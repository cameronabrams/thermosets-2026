# Molecular Simulations of Thermosetting Polymers

Slides from a seminar in the Department of Chemical Engineering at Virginia Tech, Blacksburg, on
12 October 2026, by [Cameron F. Abrams](https://github.com/cameronabrams) (Drexel University):
how thermosets can be toughened without giving up strength or thermomechanical stability, using
*protovoids* — voids encoded by bonding geometry — and what molecular dynamics has and has not
been able to show about them.

**Read the slides:** https://cameronabrams.github.io/thermosets-2026/ — page through them on a
phone, or [download the PDF](https://cameronabrams.github.io/thermosets-2026/thermosets-2026-abrams.pdf).

34 slides and 3 backup slides. The networks in the later slides are built with
[htpolynet](https://github.com/cameronabrams/htpolynet) ([docs](https://htpolynet.readthedocs.io/)),
which is free to take and use.

One section shown in the seminar is not included here: it reports unpublished results and will
appear once that work is published.

This repository holds only the rendered talk. It is published so that the QR code on the title
slide resolves for anyone in the room.
